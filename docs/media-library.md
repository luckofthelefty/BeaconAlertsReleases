# Media Library

The media library is where you manage the images, videos, GIFs, and audio files used in your alerts. Files are stored locally on your machine.

---

## Adding files

Click **Add Files** to open a file picker. You can select multiple files at once. Files are registered by path, so they do not need to be copied anywhere.

You can also drag and drop files directly onto the library grid.

---

## Browsing the library

Use the toolbar to filter and sort your files:

- **Type filter** - show All, Images, Video, or Audio
- **Sort** - sort by Newest, Oldest, Name, or Size
- **Search** - filter by file name

---

## Using files in alerts

When adding an image, video, GIF, or audio layer in the visual editor, click the media picker button to browse the library and select a file. The URL is filled in automatically.

---

## Copying a file URL

Each file card has a **Copy URL** button. Use this to paste the file path into any URL field in the editors.

---

## Deleting files

Click the delete icon on a file card. Before the file is removed, Beacon checks whether it is referenced by any alerts and shows you a list of where it is being used. You can still delete it even if it is in use, but the alerts referencing it will no longer display that file.
