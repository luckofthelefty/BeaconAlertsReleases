# Media Library

The media library is where you manage the images, videos, GIFs, and audio files used in your alerts.

---

## Adding files

### Desktop app

Click **Add Files** to open a file picker. Select one or more files. Files are registered by their path on disk and do not need to be copied or moved. They stay in their original location.

You can also drag and drop files directly onto the library grid.

### Web

Click **Upload** to open a file picker. Files are uploaded to the server. You can also drag and drop files onto the library grid to upload them.

---

## Browsing the library

Use the toolbar to filter and sort your files:

- **Type filter** - show All, Images, Video, or Audio.
- **Sort** - sort by Newest, Oldest, Name, or Size.
- **Search** - filter by file name.

---

## Using files in alerts

When adding an image, video, GIF, or audio layer in the visual editor, click the media picker button to browse the library and select a file. The URL is filled in automatically.

---

## Copying a file URL

Each file card has a copy icon button. Click it to copy the file URL to the clipboard. Use this to paste the path into any URL field in the editors.

---

## Deleting files

Click the trash icon on a file card. Beacon checks whether the file is referenced by any alerts and shows you a list before the deletion goes through. If the file is in use, you can still delete it, but the alerts referencing it will show a broken reference.

After confirming, the file is removed from view immediately. An **Undo** button appears in the notification for a few seconds in case you change your mind. After that window closes, the deletion is permanent.
