# Beacon Alerts (Desktop)

Desktop app for building and managing OBS overlay alerts with Streamer.bot. Runs entirely on your machine with an embedded database and local server. No external setup needed.

---

## How it works

1. Launch the app. The server and database start automatically.
2. Build overlays in the dashboard using the visual editor or HTML/CSS/JS.
3. Copy the overlay URL into OBS as a Browser Source.
4. The overlay connects to Streamer.bot on your PC.
5. Events (follows, subs, raids, etc.) trigger alerts in OBS.

---

## Features

- Visual editor or full HTML/CSS/JS sandbox
- Alert variants with conditional logic
- Queue control (pause, skip, clear, mute)
- Activity feed with replay
- Media library with local file support
- Text-to-speech (StreamElements)
- Spotify Now Playing overlay
- Overlay export and import
- Auto-updates
- Embedded database, no install needed

---

## Requirements

- Windows 10+ (64-bit)
- [Streamer.bot](https://streamer.bot) (running on the same PC as OBS)
